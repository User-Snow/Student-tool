# coding-class-ppt — 程序设计小班课 PPT Skill (模板绝对约束版)

## 功能
当用户说“做一个程序设计小班课ppt”“程序设计ppt”“小班课ppt”时，自动执行完整流程：
确定输出目录 → 收集个人信息（姓名、学号） → 创建主目录与提交版目录 → 整理题目原件 → 准备并编译 C++ 代码 → 截取包含输入回显与输出结果的控制台截图 → **严格按照模板的既有分区与设计风格生成 PPT** → 生成纯净的提交版目录 → 自检。

## 核心改进点（最高指导原则）
1. **“模板即最高准则”**：这是本 Skill 最重要的约束。AI 不能自作主张。
   - **不增**：如果模板 PPT 中没有“代码优化”或“一题多解”页，即便题目是顶级难度的算法题，PPT 中也**绝对不允许**出现这些页面。
   - **不减**：如果模板中有设计好的其他分区（如“易错点分析”、“拓展思考”、“复杂度分析”），则必须严格按照模板生成这些内容，不得遗漏。
   - **风格一致**：复用模板的母版、配色、字体，保持视觉风格完全统一。
2. **个人信息前置收集**：生成前会强制索要姓名、学号、组号，并自动填入 PPT 模板封面。
3. **严格的三要素截图**：控制台截图必须包含：① 代码文件所在目录；② 用户手动输入的样例数据（输入回显）；③ 程序的输出结果。杜绝任何缺失输入过程的截图。
4. **双目录输出**：
   - `第n次小班课/`：包含题目原件、`Code/`、`screenshot/` 和最终 PPT，用于讲师备课留档。
   - `第n次小班课提交版/`：只包含最终的 PPT 文件和 `Code/` 文件夹，用于直接打包上交。

##模板驱动与难度适配的关系
模板决定结构：PPT 长什么样、包含哪些页，完全由 references/template.pptx 决定。
难度决定深度：如果题目较难（如枚举优化、质数判定、DFS），AI 会在模板已有的“思路分析”和“逐行讲解”中写得更加深入；如果模板刚好也提供了“优化页”分区，才会在里面填入优化代码。题目简单则内容精简。

##前置条件
DeepSeek Harness（DSH）已安装并可启动。
输出机器上有 Python 3。
已安装 C++ 编译器：优先 Dev-C++，或可用 g++。

##依赖
bash
pip install python-pptx python-docx pillow
##安装
将整个 coding-class-ppt/ 文件夹放到以下任一位置：
项目级：<项目根>/.dsh/skills/coding-class-ppt/
用户级：~/.dsh/skills/coding-class-ppt/

##资源文件说明
references/template.pptx：内置模板，请务必替换为你提供的“第一次小班课”真实 PPT。这是生成的绝对依据。
references/scoring-standard.md：PPT 评分标准。

##截图要求（三要素，缺一不可）
目录可见：在 Code/ 目录下运行程序（如 D:\...\Code\Check.exe）。
输入可见：运行程序后，手动键盘输入（或粘贴）样例数据，让控制台显示出你输入的数据（回显）。
输出可见：程序执行完毕后打印的结果。
截取整个控制台窗口，保存到 screenshot/，命名 题目X_输出.png。
